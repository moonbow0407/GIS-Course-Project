# PostGIS 模块测试数据

本目录提供三组小型 GeoJSON 数据，坐标参考系统均为 WGS 84（EPSG:4326）：

- `monitoring_sites.geojson`：5 个监测点，用于测试点要素和空属性；
- `survey_routes.geojson`：3 条巡查路线，用于测试线要素；
- `management_zones.geojson`：3 个管理分区，用于测试面要素。

推荐测试流程：

1. 在“文件”标签页加载任意一个 GeoJSON 文件；
2. 在“数据库”标签页连接启用了 PostGIS 的 PostgreSQL 数据库；
3. 激活刚加载的图层，点击“导入图层”；
4. 打开“数据管理”，检查图层名称、几何类型和要素数量；
5. 删除地图中的本地图层，再通过“加载图层”从数据库加载；
6. 将地图显示坐标系改为 EPSG:3857，确认数据库图层能够重新投影并正常显示。

预期要素数量分别为 5、3、3。数据仅用于功能测试，不代表真实地理调查成果。
